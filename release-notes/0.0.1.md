Cooldown Bar 0.0.1 introduces the first public release of the macOS rate limit monitor.

## Highlights

1. A compact native panel that attaches to either side of the display.

2. Claude Code, Codex, and custom JSON command providers.

3. Freshness, source, reset time, and verification details for each reading.

4. A liquid drag state with magnetic edge attachment and Reduce Motion support.

5. Independent provider workers with bounded processes, retry backoff, and stale data protection.

6. Universal Apple Silicon and Intel release artifacts with integrity hashes.

Provider information can be delayed or cached. Cooldown Bar is not an official billing statement and does not guarantee instant accounting updates.
